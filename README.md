# Explainable Machine Learning Analysis of Child Stunting Risk and Regional Disparities in Nigeria

Analysis code accompanying the manuscript submitted to *Applied Computing and Informatics* (Emerald).

**Author:** Umar Yusuf Rimingado
**ORCID:** [0009-0003-5999-3553](https://orcid.org/0009-0003-5999-3553)
**Affiliation:** Department of Software Engineering, Bayero University Kano, Nigeria

## Overview

This repository contains the analysis pipeline used to study regional variation in child stunting determinants in Nigeria, using the 2023-24 Nigeria Demographic and Health Survey (NDHS). The analysis combines:

- Data cleaning and merging of DHS Children's, Household, and Individual Recode files
- Exploratory machine learning (logistic regression, random forest, XGBoost) with SHAP-based explainability
- A confirmatory logistic regression model testing zone x predictor interactions, with cluster-robust standard errors and multiple-comparisons correction
- Sensitivity analyses: survey weighting, inverse-probability-weighted selection-bias correction, severe stunting as an alternate outcome

## Data Availability

**This repository does not include the DHS microdata.** Per the DHS Program's terms of use, the data used in this analysis cannot be redistributed. Researchers can request access to the same dataset (Nigeria DHS 2023-24) free of charge by registering at [dhsprogram.com](https://dhsprogram.com).

Required files (place in a `data/` folder, not tracked by this repository):
- `NGKR8BFL.dta` — Children's Recode
- `NGHR8BFL.dta` — Household Recode
- `NGIR8BFL.dta` — Individual (Women's) Recode

## Reproducing the Analysis

1. Register for and download the Nigeria DHS 2023-24 dataset (see Data Availability above).
2. Place the three `.dta` files in a `data/` folder in this repository.
3. Install dependencies: `pip install -r requirements.txt`
4. Run `analysis_pipeline.py` — this reproduces the full pipeline: data merging, cleaning, exploratory analysis, model training and tuning, SHAP analysis, the confirmatory interaction model, and all sensitivity analyses reported in the manuscript.
